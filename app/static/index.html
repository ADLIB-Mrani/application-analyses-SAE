SAUVEGARDE COMPLÈTE CHIFFRÉE

Rouvrir le projet sans réimporter les réponses

Exportez une archive .sae contenant les réponses nettoyées et les réglages, protégée par une phrase secrète (au moins 12 caractères). Conservez la phrase séparément du fichier : elle n’est pas récupérable.

Les réponses demeurent potentiellement réidentifiables malgré le retrait des identifiants. Archive à conserver dans un emplacement maîtrisé. Une phrase secrète faible ou une machine compromise annule la protection.

Limites de cette première version

Le jeu de données reste en mémoire tant que le serveur tourne. Pour restaurer les réponses sans réimportation, utilisez plutôt l’archive chiffrée. Pour une utilisation réelle : authentification, stockage chiffré, journaux d’audit, stratégie RGPD et gestion robuste des sessions sont indispensables.
