## Découpage de livraison

- **M0 — Prototype exploratoire (présent archive)** : API, interface et tests de base, avec données fictives.
- **M1 — Cadrage validé** : validation du cahier des charges, des fichiers réels et des règles statistiques.
- **M2 — Moteur de données robuste** : variantes des fichiers, règles de qualité, tests unitaires.
- **M3 — Parcours d'analyse complet** : regroupements, cibles, graphiques et statistiques.
- **M4 — Fiabilisation** : authentification, sessions persistantes, RGPD, sécurité, performance.
- **M5 — Livraison** : recette par Sodebo, documentation et soutenances technique/client.

## Répartition des responsabilités (à compléter)

- Chef de projet : suivi, réunions, arbitrages, planning.
- Référent statistique : hypothèses, tests, validation scientifique.
- Développeur backend : import, traitement, sécurité, API.
- Développeur frontend : interface et ergonomie.
- Référent qualité : tests, recette, documentation et conformité.
